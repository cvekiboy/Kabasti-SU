## 1. Privacy & Zero Data Collection Statement
This application does not collect, access, store, or transmit any personal user data, unique device identifiers, behavioral telemetry, or tracking analytics to the publisher (cvekiboy) or any third party.

* **Local Application State:** The App saves user preferences, interface configurations, and layout properties entirely within your local device's browser/PWA storage engine. This data remains on your machine, is used exclusively to restore your state upon the next application launch, and is never transmitted over the network.
* **Offline Operation:** Once initialization files are cached, the application is designed to operate completely in an offline environment without requiring an active internet connection.

## 2. Network Access & Version Control Logic
To ensure map accuracy and application health, network capabilities requested by this PWA are strictly limited to the following anonymous conditional check:

1. **Version Checking:** On every launch, the application checks an external server asset (`version.json`) and compares it against your local bundled metadata (`meta.json`).
2. **Conditional Fetching:** 
   * **If versions match:** No data is downloaded. The app utilizes files exclusively stored locally within the user app data directory (`app_data`).
   * **If versions differ:** The app downloads updated static, non-personal assets—specifically language keys (`translations.json`) and geographic overlay markers (`kabasti_MZs.geojson`). This update cycle typically executes twice per year (Spring and Autumn).
3. **Anonymity:** No user metadata, IP logs, or personal parameters are processed or tracked during this version comparison request.
